title: "Activity log"
description: "See a chronological record of changes in Orbit"
---

The activity log turns changes in Orbit into short, readable entries. It is separate from [notifications](/concepts/notifications): an activity entry records what happened, while a notification calls a specific person's attention to an event.

## Project Activity view

Open a project and select **Activity** beside **List**, **Board**, and **Calendar**. The feed shows the 50 most recent events recorded for that project, newest first.

Each group includes:

- The member's avatar and name
- A relative time, with the exact date and time available on hover
- One or more descriptions of what changed
- An icon and color that distinguish actions such as creating, updating, deleting, inviting, changing a role, configuring an integration, or running an automation

Changes made by the same person within the same minute are grouped together. This keeps a short burst of edits readable without hiding the individual actions.

## Dashboard activity

The dashboard's **Recent Work Activity** panel shows the 15 latest actions attributed to you. This can include project work and account changes such as updating a password or session setting.

Use a project's **Activity** view when you want the shared history for that project, including changes made by other members.

## What gets recorded

Orbit records activity for the work you manage in the app, including:

- Creating, updating, assigning, and deleting issues
- Adding, editing, and deleting comments
- Changing project details and members
- Inviting people and changing their roles or permissions
- Managing labels, issue types, workflows, integrations, and automation rules
- Updating account profile, security, and notification settings

The wording varies with the action. Issue types, workflow statuses, members, and roles appear as recognizable badges or identities where the feed has enough context.

<Note>
  Orbit does not provide a separate account security-history page. Account-level entries can appear in your dashboard feed, but a project's Activity view contains only that project's history.
</Note>
