The dashboard is Orbit's home page. It summarizes the projects you belong to instead of focusing on one project like the [List, Board, Calendar, and Activity views](/guides/views).

## Stat cards

Four tiles summarize your available work:

| Card | Shows |
| --- | --- |
| Active Projects | The number of projects you belong to |
| Open Issues | Issues that are not in a completed workflow category |
| Critical Tasks | Issues with High priority |
| Resolution Rate | The percentage of issues in a completed workflow category |

## Visual summaries

Three cards show the same issue set from different angles:

- **Completion ratio** compares completed issues with the total.
- **Priority breakdown** splits issues into High, Medium, and Low priority.
- **Productivity trend** shows how many issues were updated on each day of the current week. Today's bar is highlighted.

## Recent work activity

**Recent Work Activity** shows the 15 latest [activity log](/concepts/activity-log) entries attributed to you. Each entry identifies the action, when it happened, and the member responsible. Changes made within the same minute are grouped together.

This feed follows your own recent actions across Orbit. To see changes from everyone in a particular project, open that project and select **Activity**.

## Projects directory

The **Projects Directory** shows up to three projects you belong to. Select a card to open the project. If you belong to more than three projects, use **View all** to open the complete Projects page.

If you do not belong to a project yet, the directory offers to create one. You can also join through a project invitation.
