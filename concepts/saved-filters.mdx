---
title: "Saved Filters"
description: "Save a combination of search and filter criteria for reuse"
---

Saved filters let you save a specific combination of search text, status, priority, labels, and assignee criteria and reapply it later with one click, instead of rebuilding it every time.

## Scope

A saved filter belongs to a single [project](/concepts/projects) — it isn't shared across projects, since the criteria that make sense (which labels, which teammates) are usually project-specific.

Orbit also stores the page context where the filter was created. That context is not currently enforced when filters are loaded, so all saved filters for the project can appear together. The current project issue views share the same filter controls, but context separation will matter if more filter surfaces are added later.

## Creating a saved filter

<Steps>
  <Step title="Set up your filters">
    Use the [filter bar](/guides/filtering-and-search) on a project's issue list to search by text and narrow by status, priority, labels, or assignee (including filtering for unassigned issues).
  </Step>
  <Step title="Save it">
    Save the current combination under a short name (up to 20 characters) so you can find it later.
  </Step>
  <Step title="Reapply it anytime">
    Pick it from the saved filters list to instantly apply that exact combination of criteria again.
  </Step>
</Steps>

## Limitations

Saved filters can be created and deleted, but not renamed or edited in place — to change one, delete it and save a new filter with the updated criteria. Anyone who can view the project can currently save or delete its filters; filters are project resources rather than private personal views.
