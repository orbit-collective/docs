Settings combines personal account preferences with project-scoped administration. Open it from the user menu in the main sidebar.

## Navigate Settings

Every available tab has its own path. Opening `/settings` redirects to `/settings/preferences`, and you can bookmark a tab such as `/settings/notifications` or `/settings/members` directly.

On desktop, the main sidebar changes to show **Account** and **Workspace** sections while you are in Settings. You can collapse or expand the sidebar; Orbit remembers that choice in your browser. On smaller screens, use the menu button to open the navigation as a drawer.

Unavailable tabs stay visible with a **Soon** state but cannot be selected and do not have a working route.

## Choose a project

Workspace settings belong to individual projects. Labels, Issue Types, Members, Roles & management, Integrations, and Automation use a project picker when you belong to more than one project.

Selecting a project reloads the current tab with `?project=<id>` and changes only the project being configured. With one project, the picker is hidden. If the URL does not name one of your projects, Orbit selects the first project available to your account.

The page can remain read-only or hide individual controls when your [roles and permissions](/guides/roles-and-permissions) do not allow a change.

## Account tabs

| Tab and path | Status | Covers |
| --- | --- | --- |
| Preferences — `/settings/preferences` | Available | Default issue view, theme, and accent color; see [Appearance](/guides/appearance) and [Views](/guides/views) |
| Profile — `/settings/profile` | Available | Display name and avatar; see [Account](/concepts/account#profile) |
| Notifications — `/settings/notifications` | Available | Per-event in-app and email delivery; see [Notifications](/concepts/notifications) |
| Security & access — `/settings/security-access` | Available | Password, sessions, idle lifetime, and account deletion; see [Account](/concepts/account#security-and-access) |
| Export — `/settings/export` | Soon | Account data exports are not available yet |

## Workspace tabs

| Tab and path | Status | Covers |
| --- | --- | --- |
| Labels — `/settings/labels` | Available | Project label catalog; see [Project labels](/concepts/labels) |
| Issue Types — `/settings/issue-types` | Available | Types, [workflows](/guides/workflows), hierarchy, fields, and templates; see [Issue types](/concepts/issue-types) |
| Priorities — `/settings/priorities` | Soon | Configurable priority levels are not available yet |
| Documents — `/settings/documents` | Soon | Workspace document management is not available yet |
| Members — `/settings/members` | Available | Membership, invitations, project details, and ownership; see [Manage members and roles](/guides/members-and-roles) |
| Roles & management — `/settings/roles-management` | Available | Base and custom role permissions; see [Roles and permissions](/guides/roles-and-permissions) |
| Integrations — `/settings/integrations` | Available | Connection status and configuration for external services |
| Automation — `/settings/automation` | Available | Project automation rules, triggers, conditions, and actions |

<Note>
  Workflows, hierarchy, fields, and templates are managed inside **Issue Types**. They are not separate Settings tabs.
</Note>
