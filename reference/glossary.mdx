---
title: "Glossary"
description: "Orbit's terms, defined precisely"
---

<ResponseField name="Project" type="concept">
  The top-level container for work, membership, configuration, integrations, and automation. See [Projects](/concepts/projects).
</ResponseField>

<ResponseField name="Issue" type="concept">
  A unit of work inside one project. See [Issues](/concepts/issues).
</ResponseField>

<ResponseField name="Issue type" type="configuration">
  The shape of an issue, including its workflow, hierarchy rules, custom fields, and templates. Examples include Task, Bug, and Story. See [Issue types](/concepts/issue-types).
</ResponseField>

<ResponseField name="Workflow status" type="issue field">
  The detailed step an issue currently occupies in its type's workflow, such as **Triaged** or **In review**. Each issue type can define its own statuses. See [Configure workflows](/guides/workflows).
</ResponseField>

<ResponseField name="Workflow category" type="configuration">
  One of the three broad groups—To Do, In Progress, or Done—assigned to every workflow status. Shared Board columns display these as Open, In Progress, and Done.
</ResponseField>

<ResponseField name="Priority" type="issue field">
  The urgency of an issue: Low, Medium, or High. New issues created from the inline row start at Medium.
</ResponseField>

<ResponseField name="Project label" type="configuration">
  A reusable name from one project's label catalog. Issues, templates, imports, saved filters, and automation rules can refer to it. See [Project labels](/concepts/labels).
</ResponseField>

<ResponseField name="Sub-issue" type="concept">
  An issue nested below another issue in the same project. The parent type's hierarchy settings decide which child types are allowed.
</ResponseField>

<ResponseField name="Custom field" type="configuration">
  A type-specific issue property configured as short text, long text, number, date, choice, checkbox, or link.
</ResponseField>

<ResponseField name="Template" type="configuration">
  Defaults attached to an issue type that can prefill a new issue's description and labels. See [Issue types](/concepts/issue-types#create-templates).
</ResponseField>

<ResponseField name="Creator" type="issue field">
  The user who created an issue. Orbit sets it automatically.
</ResponseField>

<ResponseField name="Assignee" type="issue field">
  The project member currently responsible for an issue. Assignment is optional and distinct from the creator.
</ResponseField>

<ResponseField name="List, Board, Calendar, Activity" type="views">
  The four project views: a structured issue list, broad drag-and-drop status columns, a dated calendar, and recent project history. See [Views](/guides/views).
</ResponseField>

<ResponseField name="Saved filter" type="concept">
  A named combination of issue search and filter criteria saved within one project. See [Saved filters](/concepts/saved-filters).
</ResponseField>

<ResponseField name="System role" type="permissions">
  One of the built-in project roles: Owner, Admin, Member, or Viewer. Every project member has one base tier. See [Roles and permissions](/guides/roles-and-permissions).
</ResponseField>

<ResponseField name="Custom role" type="permissions">
  A project-specific set of permissions that adds access on top of a member's system role. Custom roles cannot remove access supplied elsewhere.
</ResponseField>

<ResponseField name="Integration" type="configuration">
  A project-specific connection to an external service. Available integrations currently include Discord, Jira, and GitHub. See [Integrations](/guides/integrations).
</ResponseField>

<ResponseField name="Development panel" type="issue area">
  The section on an issue that lists linked GitHub pull requests and, when a repository is connected, offers branch and pull-request creation. See [GitHub integration](/guides/github-integration).
</ResponseField>

<ResponseField name="Automation rule" type="configuration">
  A project rule with one trigger, optional AND-combined conditions, and ordered actions that modify or notify about the related issue. See [Automation](/guides/automation).
</ResponseField>

<ResponseField name="Notification" type="concept">
  A per-user alert delivered in-app, by email, or both. It calls someone's attention to an event and is distinct from shared project history. See [Notifications](/concepts/notifications).
</ResponseField>

<ResponseField name="Activity log" type="concept">
  A chronological project history visible in the Activity view, with a smaller personal Recent Work Activity feed on the dashboard. See [Activity log](/concepts/activity-log).
</ResponseField>

<ResponseField name="Dashboard" type="concept">
  The overview of your projects, assigned work, deadlines, and recent activity. See [Dashboard](/concepts/dashboard).
</ResponseField>

<ResponseField name="Settings" type="concept">
  The area for account preferences and project-scoped administration. Available Workspace pages include Labels, Issue Types, Members, Roles & management, Integrations, and Automation.
  Other entries can be marked Soon. See [Settings](/concepts/settings).
</ResponseField>
