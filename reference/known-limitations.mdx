---
title: "Known limitations"
description: "Current product boundaries and unavailable capabilities"
---

Orbit is under active development. The following limits apply to the current user experience.

## No public or programmatic API

Orbit's browser application does not expose a supported public API or an external-client authentication flow. See [Tech stack](/architecture/tech-stack#why-no-api).

## No email address changes

You can change your name, avatar, and password and delete your account, but you cannot change the email address registered to it through Orbit. See [Account](/concepts/account#profile).

## Saved filters cannot be edited or context-isolated

Saved filters can be created and deleted, but not renamed or edited in place. Delete and recreate one to change it.

Each saved filter belongs to a project, and project membership is enforced when creating or deleting it. Orbit stores a view context with the filter but does not currently use that context to separate the filters loaded within the project. See [Saved filters](/concepts/saved-filters#limitations).

## Most integration cards are previews

Discord, Jira, and GitHub are available. Most other cards in the integration catalog are marked **Soon**: you can read their overview, but you cannot enable or configure them. See [Integrations](/guides/integrations#available-and-coming-soon).

## Automation conditions are flat

Every condition in an automation rule must match. The builder has no OR branches or nested condition groups, so alternative paths require separate rules. The displayed **is one of (comma-separated)** operator also does not currently convert typed text to the list expected by the rule engine; use separate **equals** rules. See [Automation](/guides/automation#add-conditions).

## Keyboard shortcuts are incomplete

`Ctrl+K` opens the shortcuts help modal rather than a distinct command palette. Orbit also has no Mac-specific `Cmd` equivalents for its shortcuts. See [Keyboard shortcuts](/guides/keyboard-shortcuts).

## No push notifications

Orbit supports in-app and email notifications, but not browser or mobile push notifications. See [Notifications](/concepts/notifications).

<Tip>
  A control can also be absent or read-only because of the selected project's permissions; that is expected access control, not a product limitation. See [Roles and permissions](/guides/roles-and-permissions).
</Tip>
