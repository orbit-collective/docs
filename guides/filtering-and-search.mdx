The filter bar narrows the issues shown in a project's [List, Board, and Calendar views](/guides/views). It is hidden in Activity because that view shows events rather than issue rows.

## Search

Search matches against an issue's title, description, ID, and labels. It's a simple substring match, not fuzzy search — searching for part of a word finds issues containing that text.

## Filters

You can combine any of the following at once:

- **Status** — one broad workflow category. The menu offers `Open` and `In Progress` for unfinished work.
  `Closed` selects completed work; the filter does not list every custom workflow status.
- **Priority** — `Low`, `Medium`, `High`
- **Labels** — one or more [project labels](/concepts/labels) from the current project's catalog
- **Assignee** — a specific person, or **Unassigned** to find issues nobody owns yet

Different filter types are combined. Within a multi-select filter such as Labels, Priority, or Assignee, an issue can match any selected value. The Status filter accepts one category at a time.

## Sorting

In the List view, select a column header to sort by ID, title, type, status, assignee, priority, labels, last updated, start date, or end date. Select it again to reverse the direction.

## Saving a combination for reuse

If you apply the same search and filters repeatedly, save the combination as a [saved filter](/concepts/saved-filters). For example, save "my open work" or "unassigned high-priority issues" and reapply it in one selection.
