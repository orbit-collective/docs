---
title: "Onboarding"
description: "The guided flows shown when you first use Orbit"
---

Orbit tracks two onboarding flows independently for each account.

## Welcome onboarding

Every new user sees a general welcome walkthrough the first time they sign in. It introduces the main parts of the app. Completing it prevents the walkthrough from appearing again for that account.

## Project onboarding

After the welcome walkthrough, Orbit offers project setup when you have not completed project onboarding and do not yet belong to any projects. You can create a project with a name, description, and color, or skip the flow.

Creating a project makes you that project's [Owner](/guides/roles-and-permissions#base-tiers). Registration order does not create a global Admin account.

If you register or sign in through a valid invitation, Orbit adds you to the invited project instead. The project onboarding prompt is not shown while you already belong to a project.

## Show onboarding again

The two completion states are saved on your account. Orbit does not currently provide a setting to reset either flow from the interface.
